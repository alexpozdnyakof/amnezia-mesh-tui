# awg-mesh-tui

Опенсорсная TUI-панель управления для любого деплоя amnezia-mesh (Rust, ratatui). Источник истины — `plan.md` в этом каталоге: читай его перед любой работой (главный флоу, контракт с сервером, решения, milestone'ы).

Связанное:

- `../amnezia-mesh` — python CLI, canonical-реализация и источник фикстур.
- `../awg/plan.md` — мастер-план (Эпик 2 — этот проект).

Границы скоупа:

- Панель универсальна: без привязок к личным сервисам/инфраструктуре конкретных пользователей; частные интеграции — только через generic хуки конфига.
- Главный флоу — мастер миграции: выбор AmneziaWG-контейнера из списка → `awg-mesh adopt` → дашборд сервисов.
- Транспорт к серверу — только shell-out по ssh (системный клиент); приложение ничего не слушает снаружи.
- Read-only по умолчанию; мутации сети — только с явным подтверждением пользователя в UI.
- Секреты (приватные ключи, PSK) не хранить дольше момента показа.
